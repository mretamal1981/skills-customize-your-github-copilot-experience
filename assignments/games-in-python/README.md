# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. This assignment helps students practice core programming concepts while creating an interactive and fun project.

## 📝 Tasks

### 🛠️ Create the Core Game Logic

#### Description
Write a Python program that lets a player guess letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Use a predefined list of words and randomly select one for each game
- Display the hidden word as underscores, such as `_ _ _ _ _`
- Accept one letter guess at a time from the player
- Reveal correctly guessed letters in the correct positions
- Track incorrect guesses and remaining attempts
- End the game when the player guesses the word correctly or runs out of attempts
- Print a clear win or lose message at the end

### 🛠️ Improve the Player Experience

#### Description
Add basic game polish so the program is easier to use and more engaging for the player.

#### Requirements
Completed program should:

- Show the letters the player has already guessed
- Prevent duplicate guesses from being counted multiple times
- Validate that the player enters a single letter before continuing
- Keep the game loop clear and easy to follow
- Use simple messages that explain the current state of the game
